## QUESTIONS BEFORE BOOKING

Ask these on the booking form (Calendly: Edit event → Invitee Questions):

```
1. اسم شركتك / Your company name? *
2. ايش أكبر تحدي بتشتغل عليه دلوقتي؟ / What's the #1 thing you're trying to solve right now? *
3. رقم واتساب (احتياطي) / WhatsApp number (backup) — optional
4. شفت أي صفحة في الموقع لفتت نظرك؟ / Did any page on the site catch your attention? — optional
```

The 2 starred questions are essential — they let you prep before the call.

- [ ] Title: `30-Min Discovery — LEOMAX`
- [ ] Duration: 30 minutes
- [ ] Location: Zoom (or Google Meet) — auto-generated per call
- [ ] Color: Black (Apple feel)

### **Availability**
- [ ] Time zone: **Asia/Riyadh**
- [ ] Days: **Sun, Mon, Tue, Wed, Thu** (skip Fri/Sat)
- [ ] Hours: **10:00 AM – 4:00 PM** (skip lunch 1:00-2:00 PM if you want)
- [ ] Minimum scheduling notice: **2 hours** (so people don't book last-minute)

- [ ] Before event: **15 min** (prep)
- [ ] After event: **15 min** (follow-up notes)

- [ ] Reminder email: **24 hours before** (use template above)
