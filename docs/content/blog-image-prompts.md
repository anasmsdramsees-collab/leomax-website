## How to use these prompts

**For ChatGPT (GPT-4o / GPT-Image):**
1. Open ChatGPT
2. Paste one prompt
3. Add: "Generate this as a 16:9 image, photo-realistic, Apple keynote aesthetic"
4. Iterate if needed (add: "make it darker", "more minimal", "remove the [thing]")

**For DALL-E 3 (via ChatGPT Plus):**
Same — but DALL-E 3 follows the prompts very literally. Use them as-is.

**For Midjourney:**
Add `--ar 16:9 --style raw --v 6` at the end of each prompt.
Optional: add `--s 100` for less stylization.

**For Adobe Firefly / Sora-style:**
Each prompt works as-is. Specify "photo-realistic, monochrome, Apple aesthetic" at start.
